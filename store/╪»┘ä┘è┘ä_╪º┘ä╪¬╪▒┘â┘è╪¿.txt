===========================================================
  متجر الغنيمة — دليل التركيب والتشغيل
  متجر رقمي كامل: عرض منتجات، سلة، دفع، ولوحة تحكم
===========================================================

المتطلب الوحيد:
Node.js
بإصدار 22.5 أو أحدث. لا توجد أي مكتبة خارجية، ولا حاجة إلى
npm install
إطلاقًا.


-----------------------------------------------------------
1) التشغيل في أقل من دقيقة
-----------------------------------------------------------

فك الأرشيف، ثم من داخل مجلد المشروع نفّذ:

    node server.js

سيطبع لك في الطرفية:

    المتجر يعمل على: http://localhost:3000
    لوحة التحكم:     http://localhost:3000/admin

    ===== بيانات الدخول (تظهر مرة واحدة) =====
    المستخدم: admin
    كلمة المرور: ...........
    ==========================================

انسخ كلمة المرور فورًا، فهي تظهر مرة واحدة فقط عند أول تشغيل.
يمكنك تحديدها مسبقًا بهذه الطريقة:

    ADMIN_USER=owner ADMIN_PASS=YourStrongPass node server.js

لتغيير المنفذ:

    PORT=8080 node server.js


-----------------------------------------------------------
2) أول خمس خطوات بعد التشغيل
-----------------------------------------------------------

1. ادخل لوحة التحكم على المسار
   /admin

2. من صفحة الإعدادات: اكتب اسم المتجر، والعملة، ورابط الموقع في
   الحقل
   base_url
   مثال:
   https://yourdomain.com
   هذا الحقل مهم جدًا، لأن بوابات الدفع ترجع المشتري إليه.

3. من الإعدادات: ضع بيانات حسابك البنكي (البنك، الآيبان، اسم صاحب
   الحساب).

4. من صفحة الإعدادات: غيّر كلمة مرور الدخول من القسم الأخير.

5. من صفحة المنتجات: أضف منتجاتك وصورها، واحذف المنتجات التجريبية
   الستة الموجودة.


-----------------------------------------------------------
3) استقبال المبالغ — ثلاث طرق جاهزة
-----------------------------------------------------------

* التحويل البنكي (يعمل فورًا بدون أي حساب خارجي)
  المشتري يرى بيانات حسابك، يحوّل، ثم يرفع صورة التحويل من صفحة
  طلبه. يتحول الطلب تلقائيًا إلى حالة «بانتظار المراجعة»، وتظهر لك
  صورة التحويل في اللوحة. تضغط «مدفوع» فيتم التسليم.

* البطاقات عبر
  Stripe
  يعمل مع مدى وفيزا وماستركارد وApple Pay. من لوحة تحكم
  Stripe
  انسخ المفتاح السري ثم الصقه في إعدادات المتجر وفعّل الخيار.
  المشتري يُحوَّل لصفحة الدفع، وعند نجاحه يتأكد الطلب تلقائيًا
  ويُسلَّم فورًا.

* PayPal
  الصق
  Client ID
  و
  Secret
  في الإعدادات. اتركه في وضع التجربة أولًا، وبعد نجاح تجربة كاملة
  فعّل خيار وضع الإنتاج.

ملاحظة صريحة ومهمة: لا يمكن لأي سكربت أن يستقبل الأموال نيابةً
عنك. المبالغ تصل إلى حسابك البنكي أو حساب التاجر الذي تفتحه بنفسك
في
Stripe
أو
PayPal
والسكربت مهمته أن يتحقق من الدفع ويؤكد الطلب تلقائيًا. المتاجر
الإماراتية والسعودية تقبل أيضًا بوابات مثل
Tap
و
PayTabs
وطريقة ربطها مشابهة تمامًا لطريقة
Stripe
إن رغبت بإضافتها لاحقًا.


-----------------------------------------------------------
4) التسليم التلقائي للمنتجات الرقمية
-----------------------------------------------------------

في صفحة تعديل أي منتج يوجد قسم «أكواد التسليم التلقائي». ضع كل كود
في سطر مستقل. عند تأكيد الدفع يُسحب من هذه الأكواد بعدد الكمية،
ويظهر للعميل مباشرة في صفحة طلبه، وتتحول حالة الطلب إلى «تم
التسليم» دون أي تدخل منك.

إن كان المنتج يُسلَّم يدويًا (مثل التسليم داخل سيرفر اللعبة)، اترك
قسم الأكواد فارغًا واكتب تفاصيل التسليم في حقل «تفاصيل التسليم»
داخل صفحة الطلب.


-----------------------------------------------------------
5) الرفع على استضافة حقيقية
-----------------------------------------------------------

الطريقة الأولى — استضافة تدعم
Node.js
مثل
Railway
أو
Render
أو
VPS

  1. ارفع الملفات.
  2. اجعل أمر التشغيل:
     node server.js
  3. اضبط متغير
     PORT
     حسب ما تطلبه المنصة.
  4. مهم: مجلد
     data
     يجب أن يكون على قرص دائم، لأن قاعدة البيانات والصور داخله.

الطريقة الثانية — سيرفر خاص مع
Nginx

  شغّل المتجر بواسطة
  pm2
  ثم مرّر الطلبات إليه:

      pm2 start server.js --name ghanima
      pm2 save

  ومثال إعداد
  Nginx

      server {
        server_name yourdomain.com;
        location / {
          proxy_pass http://127.0.0.1:3000;
          proxy_set_header Host $host;
          proxy_set_header X-Forwarded-Proto $scheme;
        }
      }

  ثم فعّل شهادة
  SSL
  عبر
  certbot
  لأن بوابات الدفع تتطلب
  https


-----------------------------------------------------------
6) النسخ الاحتياطي
-----------------------------------------------------------

كل شيء داخل مجلد واحد هو
data

    data/store.db        قاعدة البيانات كاملة
    data/uploads/        صور المنتجات وصور التحويلات
    data/secret.key      مفتاح توقيع الجلسات

انسخ هذا المجلد دوريًا. لاستعادة المتجر بالكامل ضعه في مكانه
وشغّل السكربت.

تنبيه: لا تشارك ملف
secret.key
مع أحد، ولا ترفعه على
GitHub


-----------------------------------------------------------
7) بنية الملفات
-----------------------------------------------------------

    server.js              كل المسارات: المتجر، السلة، الدفع، اللوحة
    lib/db.js              قاعدة البيانات والجداول والبيانات التجريبية
    lib/core.js            الجلسات، الكوكيز، حماية
                           CSRF
                           ورفع الملفات
    lib/payments.js        بوابات الدفع
    views/store.js         صفحات المتجر
    views/admin.js         صفحات لوحة التحكم
    public/css/app.css     التصميم كامل
    public/js/app.js       سكربت الواجهة
    data/                  يُنشأ تلقائيًا عند أول تشغيل


-----------------------------------------------------------
8) ما تم اختباره فعليًا قبل التسليم
-----------------------------------------------------------

شُغّل السكربت واختُبر بالكامل عبر طلبات حقيقية، ونجحت هذه الحالات:

    - عرض الرئيسية والتصنيفات وصفحة المنتج والبحث
    - إضافة للسلة، وتحديث الكميات، وتقييد الكمية بالمخزون المتاح
    - كود خصم بنسبة 20% وحساب الخصم والإجمالي بدقة
    - إنشاء طلب بالتحويل البنكي ورفع صورة التحويل
    - تأكيد الدفع من اللوحة، ونقص المخزون، وزيادة عدد المبيعات
    - التسليم التلقائي: طلب بكمية 2 استلم كودين، وبقي كود واحد
    - دخول اللوحة، ورفض كلمة المرور الخاطئة، وتغيير كلمة المرور
    - إنشاء منتج وتصنيف وكود خصم، وحذف منتج، ورفع صورة
    - رفض أي طلب بدون رمز
      CSRF
    - رفض الوصول للوحة بدون جلسة
    - منع تجاوز المسارات في الملفات الثابتة

ما لم يُختبر: بوابتا
Stripe
و
PayPal
لأن اختبارهما يحتاج مفاتيح حسابك الحقيقية واتصالًا بالإنترنت.
جرّبهما في وضع التجربة أولًا بمبلغ صغير قبل النشر.
